# Kodograf VVGU

A web-based learning environment where students can read a lesson, write code and run Python directly in the browser.

> An independent learning concept, not an official VVGU service or university partnership.

| Fact | Details |
|---|---|
| Format | Interactive learning environment |
| Status | Verified locally · source code is not published |
| Stack | `Next.js` `Monaco` `Pyodide` `Web Worker` `Sandbox` |
| Source | Not included in this showcase repository |

## Learning loop

Keep explanation and practice on one screen so a student can move quickly from an example to their own solution.

## Student tools

- lessons and practical exercises;
- a Monaco editor with Python execution;
- solution checks and a separate sandbox;
- a learning flow adapted to mobile screens.

## Execution isolation

Python execution through Pyodide, computation isolated in a Web Worker and a complex editor that does not block the main interface.

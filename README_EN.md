# Kodograf VVGU

A browser workspace for learning Python. The student reads a task, edits code and sees its output in the same tab.

![Kodograf VVGU — Editor and execution output](assets/social-preview.jpg)

Locally evaluated prototype · Public showcase of a private project  
Next.js · Monaco Editor · Pyodide · Web Worker

## From the lesson to Python output

**Editing.** The explanation and example stay beside Monaco Editor. Students can check their solution and then experiment in a separate sandbox.

**Execution.** Pyodide runs Python in a Web Worker. The main browser thread remains available for the interface while the interpreter runs. Exercise checking happens on the client.

An independent educational concept using the VVGU name, with no official university affiliation.

## A Python lesson across two screens

**[The mobile exercise](assets/screen-lesson-mobile.jpg)** · The Hello World lesson introduces the task and example before the learner starts editing.

**[The desktop workspace](assets/screen-python-run-desktop.jpg)** · The prompt stays to the right of the code. The output area beneath the editor lets the learner compare the result with the example in the same tab.
